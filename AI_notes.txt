Move Claude to another computer

On the new machine, install Claude Code as usual — see [Setup](/en/setup) for platform-specific instructions (native installer, Homebrew, WinGet, npm, etc.), then sign in with `claude auth login` or `/login`.

On the old machine, uninstall using the method matching how you installed it, per the [Uninstall Claude Code](/en/setup#uninstall-claude-code) section:
- **Native installer**: delete `~/.local/bin/claude` and `~/.local/share/claude` (Windows: the corresponding `%USERPROFILE%\.local\bin\claude.exe` and `%USERPROFILE%\.local\share\claude`)
- **Homebrew**: `brew uninstall --cask claude-code`
- **WinGet**: `winget uninstall Anthropic.ClaudeCode`
- **apt/dnf/apk**: package-specific remove commands
- **npm**: `npm uninstall -g @anthropic-ai/claude-code`

Your settings, `CLAUDE.md`, and project configs live under `~/.claude/` — note the page's warning that deleting that directory removes all settings, allowed tools, MCP configs, and session history, so back it up first if you want to carry it to the new machine.

09/24
Porting to LENOVO:
Since both machines run Ubuntu, here are the exact commands. Replace ~/myproject with your actual folder and YOUR-USERNAME/YOUR-REPO with your GitHub details.

On the laptop

1. Install git and the GitHub CLI, then log in to GitHub:

bash
sudo apt update
sudo apt install -y git gh
gh auth login

When gh auth login asks, choose GitHub.com, HTTPS, and log in with a web browser. It also sets up git so pushes don't ask for a password.

2. Set your git identity (one time only):

bash
git config --global user.name "Barry"
git config --global user.email "barry@dcsmail.net"

3. Update CLAUDE.md with your progress. In Claude Code, ask:

"Create or update CLAUDE.md with a summary of the project, what we've done, key decisions, and next steps."

4. Create a .gitignore. Change the entries to fit your project:

bash
cd ~/myproject
cat >> .gitignore << 'EOF'
.env
*.key
node_modules/
__pycache__/
.venv/
.claude/settings.local.json
EOF

5. Commit and create the private GitHub repo in one go:

bash
git init -b main
git add .
git status          # look over the list for secrets or big files first
git commit -m "Initial commit of existing work"
gh repo create YOUR-REPO --private --source=. --push

The last command creates the repo on GitHub and pushes to it, so you don't need to visit the website.

On the Lenovo

6. Install the tools and log in:

bash
sudo apt update
sudo apt install -y git gh
gh auth login
git config --global user.name "Barry"
git config --global user.email "barry@dcsmail.net"
curl -fsSL https://claude.ai/install.sh | bash

The last line is Claude Code's official installer. Open a new terminal afterward so the claude command is found.

7. Clone the repo and start Claude Code. Put it at the same path as on the laptop (see step 8):

bash
cd ~
gh repo clone YOUR-USERNAME/YOUR-REPO myproject
cd myproject
claude

The first time you run claude, it will ask you to sign in.

8. Copy over what git doesn't carry. If SSH is set up between the two machines, scp is the easiest way. Otherwise use a USB stick.

bash
# Run on the laptop. Replace lenovo-hostname with the desktop's name or IP.
scp ~/myproject/.env lenovo-hostname:~/myproject/

Optional: bring your old chat history along. Claude Code keeps it in ~/.claude/projects/, in a folder named after the project's path (for example -home-barry-myproject). If your Linux username and project path are the same on both machines, you can copy it over and claude --resume will list your old sessions:

bash
# Run on the laptop.
scp -r ~/.claude/projects/-home-barry-myproject lenovo-hostname:~/.claude/projects/

If the paths differ, skip this and rely on CLAUDE.md.

Daily routine

Start each work session with:

bash
git pull

End it with:

bash
git add . && git commit -m "Describe what changed" && git push

You can also just tell Claude Code "commit and push my changes."
